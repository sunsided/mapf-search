# mapf-search

Multi-agent pathfinding: CBS, ECBS, CBS-TA, ICTS, PBS, M* and MAPF-LNS2.

## Planned scope

- Conflict-based: CBS, ECBS, CBS-TA
- Cost-vector search: ICTS
- Priority-based: PBS
- Subdimensional: M*
- Local repair: MAPF-LNS2
- Partial expansion: EPEA*

## Status

Pre-release. Milestone 1 (instance types, conflict detection, space-time A*, optimal CBS
for sum of costs) is drafted; the API will change. See [docs/design.md](docs/design.md).
