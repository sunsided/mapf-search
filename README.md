# mapf-search

Multi-agent pathfinding: CBS, ECBS, CBS-TA, ICTS, PBS, M* and MAPF-LNS2.

## Planned scope

- Conflict-based: CBS, ECBS, CBS-TA
- Cost-vector search: ICTS
- Priority-based: PBS
- Subdimensional: M*
- Local repair: MAPF-LNS2
- Partial expansion: EPEA*

## Status

Pre-release. Milestones 1 and 2 are drafted: instance types, conflict detection,
space-time A*, CBS that is optimal for sum of costs or makespan, and Moving AI `.map`/`.scen`
parsers; the API will change. See [docs/design.md](docs/design.md).
